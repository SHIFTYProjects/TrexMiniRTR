# TrexMiniRTR
Trex Mini for your EDR/MDR/SIEM/SOAR to run with RTR.


Add this to your vendors such as Crowdstrike, SentinalOne's Real Time Response Script to do a full data pull from the endpoint with event logs, security logs, applications, prefetch, full web history etc.




Works and runs in about 25-60 Seconds.  Then run a get from the CLI to claim the zipped folder.


Zipped Forensic File for Windows in located in "c:\<Computername>_TrexReport.zip"

Zipped Forensic File for Mac is located in the root directory. "\<Computername>_TrexReport.zip"
